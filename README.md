# TechnicalAnalysis

Coursework repository for BDA400 (Data Science Tools and Techniques), by Haseeb.

## Contents

- `Assignment2/` Preliminary stage: portfolio loading, statistics and display functions (quantmod, Yahoo Finance).
- `Assignment5/` Development phase: nine technical indicators implemented from pseudocode in base R (sma, ema, macd, stdev, linreg, rsi, stoch_rsi, crossover, crossunder).
- `Assignment6/` Visualization phase: Shiny portfolio dashboard with chart types, indicator overlays and SMA 20/50 crossover Buy/Sell annotations.

Run the dashboard with `shiny::runApp("Assignment6/haseeb_portfolio_dashboard.R")` after installing shiny, ggplot2 and quantmod.
